# 🚕 Uber Ride Request Analysis

## 📌 Project Overview

This project analyzes **Uber ride request data** to identify supply-demand gaps, understand trip failures, and uncover opportunities for improving ride fulfillment.

The project follows an end-to-end data analysis workflow, from **data cleaning and transformation** to **SQL-based analysis and interactive dashboard creation**.

Key areas analyzed include peak-hour cancellations, driver availability, trip duration, and location-based fulfillment gaps, with a particular focus on the **airport**.

---

## 🎯 Business Objectives

* Identify major reasons for failed ride requests.
* Analyze supply-demand gaps across different locations and time periods.
* Identify peak hours with high cancellation rates.
* Analyze driver availability and trip fulfillment.
* Calculate key metrics such as average trip duration and request volume.
* Provide data-driven recommendations to improve ride fulfillment.

---

## 🔧 Skills & Tools Used

* 🐍 **Python (Pandas)** — Data cleaning, transformation, and feature engineering
* 🧮 **MySQL** — Business metric analysis and data validation
* 📊 **Excel** — Dashboard creation using Pivot Tables, Charts, KPI Cards, and Slicers
* 📁 **Data Wrangling** — Date-time parsing, missing-value handling, and column formatting
* 📈 **Data Visualization** — Interactive dashboard and multi-chart analysis
* 💡 **Analytical Thinking** — Identifying trends, patterns, and operational gaps

---

## 🔍 Key Analysis

The analysis focuses on:

* 🚫 Ride cancellations during peak hours
* 🚗 Driver availability across locations
* ✈️ Supply-demand issues around the airport
* ⏱️ Average trip duration
* 📊 Ride request and fulfillment patterns
* 📈 Time-based demand and supply trends

---

## 💡 Key Insights

* Peak hours showed increased ride cancellations due to limited driver availability.
* The **airport** experienced significant supply-demand imbalance.
* Certain time periods showed consistently higher ride requests than available drivers.
* Trip duration and request patterns helped identify periods requiring better driver allocation.
