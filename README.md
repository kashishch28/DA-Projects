# 📊 Data Analytics & Visualization Projects

A collection of **end-to-end data analysis and visualization projects** built using Python, SQL, and Excel.

This repository demonstrates practical skills in **data cleaning, exploratory data analysis (EDA), SQL analysis, data visualization, dashboard development, and business insight generation** across different real-world datasets.

---

## 📁 Projects

### 🚕 1. Uber Ride Request Analysis

An analysis of Uber ride request data focused on identifying **supply-demand gaps, ride cancellations, and trip fulfillment issues**.

**Key Areas:**

* Data cleaning and date-time transformation
* Supply vs. demand analysis
* Peak-hour cancellation analysis
* Driver availability analysis
* Airport-specific fulfillment gaps
* Average trip duration analysis
* Business recommendations

**Tools:** 🐍 Python (Pandas) · 🧮 MySQL · 📊 Excel

---

### 🚴‍♂️ 2. Bike Dekho Sales Dashboard

An Excel-based **EDA and dashboarding project** analyzing customer demographics and bike purchasing behavior.

**Key Areas:**

* Data cleaning and preprocessing
* Age-group and income segmentation
* KPI generation
* Pivot Table analysis
* Customer purchasing behavior
* Interactive dashboard creation

**Tools:** 📊 Microsoft Excel · Pivot Tables · GETPIVOTDATA · Charts · Conditional Formatting

---

### 🧠 3. Mental Health in Tech — Survey Analysis

An exploratory analysis of survey data focused on understanding **mental health treatment and workplace factors in the technology industry**.

**Key Areas:**

* Data cleaning and preprocessing
* Exploratory data analysis
* Country-wise treatment analysis
* Work interference analysis
* Gender and treatment comparison
* Care options and treatment analysis
* Anonymity policy analysis
* Correlation analysis
* Logistic Regression model

**Tools:** 🐍 Python · Pandas · NumPy · Matplotlib · Seaborn · Scikit-learn · Jupyter Notebook
